# CoachVault Engine 3.6.4 — Public Homepage

Adds a true public landing page at `/`.

## Routing
- `/` — CoachVault marketing homepage
- `/workspace` — existing CoachVault Engine / Vault application

## Homepage strategy
Inspired by strong SaaS/product storytelling patterns:
- clear hero promise
- problem before feature dump
- simple three-step product loop
- visual product preview
- explanation of why CoachVault is more than a drill library
- entry points for coaches, clubs/programs, and coach developers
- repeated but restrained CTA to open the workspace

## Core CoachVault message
CoachVault captures, understands, and organizes coaching knowledge so coaches
spend less time preparing and more time coaching.

## Originality
The homepage does not copy POWLAX copy, branding, or page design. It borrows
high-level information architecture cues while using CoachVault's own product
language, visual system, and positioning.

## Existing functionality
All 3.6.3 background large-PDF analysis code is retained inside `/workspace`.
