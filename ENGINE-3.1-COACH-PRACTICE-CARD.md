# CoachVault Engine 3.1

## Coach Practice Card implementation

This release includes the working Coach Practice Card interface.

- Coach Practice Card opens by default for every approved drill.
- Engine Analysis is available as a second tab.
- Older approved drills receive a compatibility Coach Practice Card.
- New analyses generate setup, run sequence, coach focus, watch-for items, regressions, progressions, prerequisites, success criteria, and source provenance.
- The header displays Engine 3.1 so the active deployment is easy to verify.

## Verify after deployment

1. The top-left CoachVault header must say Engine 3.1.
2. Open any approved drill.
3. The first tab must say Coach Practice Card.
4. The second tab must say Engine Analysis.
