# CoachVault Engine 3.0

## Sprint 4: Coach Practice Card

This release adds a coach-facing execution layer to every analyzed drill.

### Engine output

The Engine now returns:

- Standardized CVIL analysis
- Coach Knowledge Model metadata
- A field-ready Coach Practice Card
- Detected, Estimated, or Not stated provenance for setup fields

### Coach Practice Card sections

- Purpose
- When to Use
- Setup
- Field Layout description
- Run the Drill
- Coach Focus
- Watch For
- Make It Easier
- Make It Harder
- Prerequisites
- Avoid If
- Success Criteria
- Coach Notes

### Vault experience

Approved drills open on the Coach Practice Card by default. Engine Analysis remains available in a second tab.

### Legacy records

Older Vault records receive a compatibility card so they remain readable. Reanalyze older sources to generate complete Engine 3.0 cards.
