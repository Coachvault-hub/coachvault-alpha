# Engine 2.0.3 Changelog

1. Existing Unfiled Vault items are migrated into suggested folders.
2. New analyses receive a suggested folder from their primary skill.
3. Skills such as Ground Balls, Cradling, Catching, Passing, and Ball Protection default to Skills.
4. Athletic Movement defaults to Player Development.
5. Defense, Offense, Transition, Goalie, and Faceoff mappings are prepared for future standards.
6. Renamed the coach-facing Skill Framework tab to Skills.
7. The Skills page now displays all six CVIL standards across the top.
8. Header metrics now show the true CVIL standard count instead of one framework.
