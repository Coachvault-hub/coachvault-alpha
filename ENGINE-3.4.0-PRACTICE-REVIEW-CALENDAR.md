# CoachVault Engine 3.4.0

## Practice review at a glance
Every generated Practice Plan now supports:
- green check: keep/approve a drill
- red X: replace only that drill
- lock: preserve a drill while other segments change
- replacement choices drawn from unused approved Vault drills

## Practice Library
Saving a practice is independent from scheduling.
Saved plans persist locally and can be reopened or reused.

## Optional Calendar
Calendar is an optional workspace.
A saved or newly built practice may be added to the calendar, but no date is required to save it.
Schedule fields:
- date
- optional time
- optional location

## Confidence display
Confidence values now safely support both 0-1 and 0-100 formats:
0.95 -> 95%
95 -> 95%

## Product principle
Build -> Review -> Save
Scheduling remains optional.
