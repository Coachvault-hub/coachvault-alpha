# Engine 1.2 Changelog

1. Scores are independent and no longer intended to total 100.
2. Ground Ball components are locked to the approved framework.
3. Misclassified components move to supporting skills or incidental actions.
4. Context is stored separately from skills.
5. Every weighted item includes a source-based reason.
6. The Engine progress display is restored.
7. Coach review is simplified.
8. Debug and raw JSON are available only when Internal Tools is enabled.
