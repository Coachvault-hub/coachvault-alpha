# CoachVault Intelligence Library v1

CVIL is the structured coaching knowledge used by CoachVault Engine 2.0.

Included standards:

- Ground Balls
- Cradling
- Catching
- Passing
- Ball Protection
- Athletic Movement

Each standard contains:

- Definition
- Purpose
- CoachVault principle
- Components
- Objectives
- Observable behaviors
- Coaching cues
- Common mistakes
- Corrections
- Progressions

The Engine matches content against exact CVIL vocabulary. It no longer invents primary skills, components, or objectives when a matching standard exists.
