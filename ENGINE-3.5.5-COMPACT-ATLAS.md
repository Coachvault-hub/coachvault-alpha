# CoachVault Engine 3.5.5 — Compact Atlas Workspace

The Atlas intake screen has been tightened so the primary action stays above the fold
on a typical desktop viewport.

Changes:
- Smaller page/header spacing
- More compact Engine Workspace card
- Shorter tab bar
- Reduced input panel padding
- Smaller recognized-source chips
- Condensed Social Video Intelligence message
- Reduced file-drop height
- Analyze button moved higher through overall layout compression
- Live Engine analysis remains high in the viewport

Goal:
The coach should see the source input AND the Analyze with CoachVault action without
scrolling during normal desktop use.
